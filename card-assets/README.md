# card-assets

This folder decides which image Holo Folder shows for every card, where that image comes from, and why. It also holds the one script that collects, uploads and records card images: `bun run card-assets`.

## Built on the PTCG Image Atlas

Our approach to sourcing card images is built on the **[PTCG Image Atlas](https://nstrelow.github.io/ptcg-image-atlas/)** by Luna ([source on GitHub](https://github.com/nstrelow/ptcg-image-atlas)). The atlas is an interactive map of where Pokémon TCG card images come from. It covers which official sites publish them, who scans or re-hosts them, who copies whom (pixel-verified where possible), what TCGdex is still missing in each language, and whose permission reusing each source would need.

Before the atlas, we picked image sources one gap at a time. It gave us the whole picture, and most of the decisions here come straight from it:

- **Which sources are official.** The atlas showed that [malie.io](https://malie.io/static/) publishes the card images from the Pokémon TCG Live and TCG Online clients at 733 × 1024. TCGdex and pokemontcg.io carry copies of those same files, at smaller sizes. That's why malie is now the first choice for 16,000 cards.
- **How big each source's images are.** The atlas lists pokemon.com's card images at 245 × 342. We were preferring them over TCGdex's 600 × 825 print for most cards; that is now fixed.
- **How to classify a source.** Our `sources.csv` uses the atlas's split between official renders, official scans, re-hosts, fan scans and retail photos.
- **Whose permission it needs.** Our `none` / `needed` / `forbidden` permission column follows the atlas's permission notes. That's why fan scans such as Martin of Pokémon Paradijs's stay off until the scanner agrees, and why we never mirror from sites whose terms forbid it.

We keep a pinned copy of the atlas data in [`pokemon/tcg/atlas/`](pokemon/tcg/atlas/) (MIT licence, with the commit it came from). Each source in `sources.csv` names its atlas id, and `bun run card-assets verify` checks our sources against it. If the atlas says a source needs someone's permission and we haven't recorded why it's fine, `verify` warns.

Thank you, Luna. Credit for the atlas also appears in the app (Settings → Credits & attributions, and [`/app/credits`](https://holofolder.com/app/credits)) and in [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## What's here

| Path | What it is |
| --- | --- |
| [`pokemon/tcg/sources.csv`](pokemon/tcg/sources.csv) | Every image source we know of: what kind of image it holds, its permission, size, credit and atlas id |
| [`pokemon/tcg/rules.csv`](pokemon/tcg/rules.csv) | Which source we prefer for which cards, from everything down to a single card |
| [`pokemon/tcg/ledger/`](pokemon/tcg/ledger/) | What every card ended up with, one CSV per set, generated by `bun run card-assets plan` |
| [`pokemon/tcg/malie-sets.csv`](pokemon/tcg/malie-sets.csv) | How our set ids map to malie's set codes |
| [`pokemon/tcg/discovered/`](pokemon/tcg/discovered/) | Per-card images found by `bun run card-assets discover` |
| [`pokemon/tcg/atlas/`](pokemon/tcg/atlas/) | The pinned PTCG Image Atlas data, its licence and source commit |
| [`AGENTS.md`](AGENTS.md) | The full guide: every command, every column, and how card ids line up across sources |

The folders follow the image bucket: brand, then game (`pokemon/tcg`), so another game can sit beside it later.

## The usual loop

```sh
bun run card-assets plan                # rebuild the ledger from the database and rules.csv
bun run card-assets verify              # check sources, rules, the atlas and what the app serves
bun run card-assets publish --apply     # upload the chosen images and make the app show them
```

To change which image a set uses, add a row to `rules.csv`, run `plan`, and review the ledger diff. It shows exactly which cards move from which source to which. Then publish. `AGENTS.md` lists the other commands (`discover`, `renditions`, `mirror-tcgdex`, `mirror-pokemoncom`, `fill-gaps`, `inventory`, `atlas` and `migrate-bucket`).

### Set artwork

Set symbols and logos use `bun run card-assets mirror-sets --apply`, independently of card scans. The committed
`pokemon/tcg/set-artwork.json` manifest records the upstream source and verified CDN URL for each file. See
[the storage guide](../docs/card-image-store.md#set-symbols-and-logos) for upload and verification steps.
