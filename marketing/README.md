# Marketing

This folder holds Holo Folder's growth research, the plan and the weekly record of progress. The [growth-loop skill](../.agents/skills/growth-loop/SKILL.md) is how an agent runs it week to week.

Start with [growth-plan.md](growth-plan.md), which covers where we are, the strategy, the decisions Cal needs to make and the 90-day sequence. The other files support it:

- [seo-audit.md](seo-audit.md) is the technical and content audit of holofolder.com, with prioritised fixes and the plan for public set, Pokémon and card pages.
- [competitors-and-keywords.md](competitors-and-keywords.md) covers fourteen competitors, where we are genuinely different, which searches are winnable and how our pricing compares.
- [channels-and-automation.md](channels-and-automation.md) covers communities and their self-promotion rules, content formats, launch platforms, creators, and which posting APIs an agent can use.
- [content-calendar.md](content-calendar.md) lists dated hooks from November 2026 to February 2027.
- [brand-voice.md](brand-voice.md) holds the voice, claims rules and account handles every published word must follow.
- [scoreboard.md](scoreboard.md) has one row a week of the numbers that matter.

Anything naming real people, such as the creator outreach list and contact notes, goes in `marketing/private/`. It is gitignored and never committed.

The research was done on 14 November 2026. Treat anything dated, such as set release dates, subreddit rules or API pricing, as something to re-check before relying on it.
