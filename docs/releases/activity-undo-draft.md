# Activity and Undo release draft

Publish after the app, migration 087, API and help are verified live. Related: #447, #396. This release does not announce native inventory/structural recovery.

Title: A clearer history, with Undo

Activity now shows what happened in plain language, grouped by day. See which card changed, who changed it and when, without wading through technical details.

Removed the wrong card or changed your want list by mistake? Choose Undo in Activity, review the change and put it back. Undo checks for newer edits first, so it won’t overwrite someone else’s work. It also leaves a new entry in your history.

Saved activity is available offline. Reconnect to undo changes. Card and want-list edits with complete history are supported; older incomplete entries, deleted collections and structural changes remain unavailable.
