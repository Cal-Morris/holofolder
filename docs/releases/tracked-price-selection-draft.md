# Tracked-card refresh selection, unpublished draft

Status: prepared for the #374/#379 feature block, not a shipped announcement. No hosted/provider verification or native editing enablement is claimed.

When native collections are enabled, tracked price refreshes will include physical copies in storage and Unassigned, plus explicit wanted cards such as Trainers and Energy. Empty targets will not request prices, and converted collections will no longer refresh frozen legacy contents. Repeated copies share the same card/language provider request. Unknown language, finish or price evidence stays unknown.

Existing refresh access, confidence and freshness rules continue to apply. This does not estimate graded market values or claim faster/cheaper pricing. Publish only after the parent verifies deployment and supported legacy/native/mixed refresh behavior. Help: `/app/docs/contracts#images-and-prices`. No new public API operation or permission.
