# Private-preserving storage edits, unpublished draft

Status: internal staged contract only. Do not publish until migrations, combined integration, recovery/rollout gates and enabled production behavior are verified by the parent. Related: #376, #383. No Framer changes made.

Proposed release copy for the eventual native storage feature block:

Update recorded grading details without resending a certificate or private label image. Fields you leave out stay as they are; explicit clears affect only the chosen public field. When assigning a copy, fulfill exactly the selected wanted entry while leaving other wants alone, including duplicate entries.

Retries retain the original operation. If a reply is lost, replay returns the original receipt and keeps later edits intact. Stale item, slot or placement versions stop the whole edit instead of overwriting a partner's changes.

Availability and limitations to include when enabled: already graded copies only for public patches, current owner/partner and paid developer permissions, exact selected-entry versions, and existing recovery limits for private label assets. Whole grading/wanted-list replacement remains an explicit separate contract.
