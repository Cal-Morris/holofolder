# Draft: Review changes saved on this device

Unpublished. Parent owns acceptance, release and publication.

Guest and older device changes can be reviewed before adding them to an explicitly
chosen binder. Review shows additions, replacements, removals and unresolved
entries, along with the destination account and sharing visibility. Original data
stays on the device and can be downloaded. Signing in or reconnecting does not
approve an upload.

A changed recipient or unknown upload outcome keeps the request on the device.
Cancelling cannot undo a request already sent. Converted-binder pauses remain in
place. Native admission, conversion and bootstrap remain staged; do not announce
those capabilities or exactly-once/crash-proof delivery.
