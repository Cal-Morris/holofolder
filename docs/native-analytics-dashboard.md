# Native analytics and storage dashboard

Related: #374, #448. This is staged presentation code, not enabled native storage or rollout acceptance (#379). Production app and developer admission remain closed.

The existing browser collection session supplies its current `CollectionNavigationRead` and independently current account/owner/session scope to `NativeCollectionAnalytics`. The same component renders the selected storage dashboard value badge and the Analytics view. The compact badge is hidden during layout editing so it cannot consume the small-screen editing space; full counts and quote dates are in Analytics. Analytics offers This storage / All storage. All storage includes Unassigned exactly once. The existing 3D dashboard still renders ordered slot display evidence, with target art distinct from owned art. No species-keyed compatibility collection is constructed.

`buildNativeAnalytics` reuses `navigationIndex`, the Inventory ownership/value projection and `getBinderGoalPresentation` / `getBinderCompletion`. Physical copies, known unique species, actual slots, explicit wants and current-target completion are separate numbers. Empty goals, spacers and wants do not become ownership. Completion uses current valid targets, including zero-target binders, without a fixed Dex denominator. Repeated raw/graded printings remain individual copies.

Saved exact canonical printing/language/finish quotes use the existing saved-price GET, deduplicated by card/language in batches of 25. No refresh POST, paid comparisons or provider calls. Value includes only finite positive medium/high confidence exact-finish raw evidence, after regional selection and freshness caps. Missing/invalid/weak evidence is unpriced; graded value stays unknown even when a raw reference exists. The view discloses priced/unpriced/graded counts, partial estimates, confidence and oldest included date. No timing signals are introduced.

Complete evidence requires the canonical complete-read brand and current scope fences. Cached or optimistic reads remain labelled Cached only / Last saved and never claim whole-inventory totals. Unavailable/unknown scope does not become a complete zero. Loaded public price evidence survives going offline in the mounted view. Reopening offline can leave quotes unknown; this slice adds no price store, per-user HTML caching or service-worker changes. Browser session remounts and synchronous summary rejection clear account/owner/session swaps. Existing current-recipient command fences remain unchanged; this is read-only and emits no audit events.

## API boundary

The existing shared `readCollectionAnalytics` operation serves both first-party `/app/api/collection-analytics` and REST/MCP `get_collection_analytics` (`GET /app/api/v1/analytics`). It remains a legacy history read, not a native inventory total API. Before any legacy activity query it checks the native owner root and pages owner-scoped storage authority, and repeats both checks before returning history. The root survives deletion of a last nondefault native collection, so retained Unassigned copies cannot be hidden behind legacy-only history. Any native owner root, converted or mixed storage returns **503 `native_analytics_staged`**, without reading frozen legacy activity. Unknown/failed authority returns 503. Missing pre-conversion schema retains legacy behavior. The existing permission requirements (`collection:read`, `prices:read`) and transport authentication remain unchanged. No credentials, private certificates/assets, full snapshot or history fields are newly exposed, and no browser cookie impersonation is used.

The native dashboard is an internal adapter over the existing fenced complete-read host. Native public inventory operations remain unconditionally 503. A future admitted analytics read needs the full native developer authority/permission boundary; this PR does not add a new operation, enable admission or represent internal complete-read evidence as a public response. The registry description, generated OpenAPI and current help state this restriction.
