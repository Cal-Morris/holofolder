# Agent-readable developer documentation

Public documentation is available without a login:

| URL                                             | Content                                                               |
| ----------------------------------------------- | --------------------------------------------------------------------- |
| `/app/llms.txt`                                 | Guide and endpoint index linking to Markdown pages                    |
| `/app/llms-full.txt`                            | Every guide and endpoint contract in one text response                |
| `/app/docs/llms.txt`, `/app/docs/llms-full.txt` | Equivalent URLs within the docs section                               |
| `/app/docs/markdown`                            | Overview as Markdown                                                  |
| `/app/docs/markdown/<page>`                     | A guide or endpoint as Markdown, using the same slug as its HTML page |
| `/app/openapi.json`                             | OpenAPI 3.1 REST contract                                             |

Each HTML page advertises its `text/markdown` alternate and shows “View as Markdown” and `llms.txt` links. These paths retain the `/app` prefix and work through the public host or directly on the Vercel origin.

Fumadocs generates the index from the existing page tree. `lib/docs-navigation.ts` groups the long Collection and Prices and insights sections by subject for both the sidebar and agent index. The grouping preserves the generated operation URLs, Markdown paths and REST/MCP contracts; new operations without an assigned subject remain visible under Other operations. Guide Markdown is compiled from the same MDX with `includeProcessedMarkdown`; the Markdown-only Card, Callout and DocsLink renderers preserve useful labels, descriptions and links without exporting JSX. Endpoint Markdown serializes the exact operation from `public/openapi.json`, which is generated by `scripts/generate-api-docs.ts` from the operation registry. Do not maintain a separate copy of agent documentation.

Only public documentation and schemas are exported. These endpoints do not read account data or bypass API authentication. REST still requires a personal key; MCP uses OAuth. Missing response schemas remain undocumented rather than being guessed.

Verification: `bun test tests/docs-markdown.test.ts`; focused Playwright coverage in `e2e/docs-llms.e2e.ts` checks both indexes, all registered operations, exact endpoint contracts, discovery links and 404s. Regenerate OpenAPI after operation changes with `bun scripts/generate-api-docs.ts`.

Private committed history: use list_collection_audit/get_collection_audit with collection:read and current paid developer access. Follow nextCursor with unchanged filters; event IDs are strings. Unknown legacy actors are intentional. Recovery columns, certificate/label assets and share tokens are absent. A failed history read returns `503 audit_unavailable`.

Native storage reads, commands, creation, presets and recovery are generated from the same registry and admitted through the authenticated bridges. The `/app/docs/native-storage`, `/app/docs/native-reads` and `/app/docs/preset-previews` guides and their Markdown/LLM exports explain operation-ID replay, revision-bound pagination and redaction. A returned developer page is not a complete snapshot or fresh-read acknowledgement; certificates, private assets and immutable planning evidence are excluded. Agents must not use an unrelated browser session, public share or fabricated authentication to obtain private inventory state.

The native command schemas export optional `privateFields:preserve|replace`. Preserve mode requires `expectedOwnerUserId` and rejects a changed authenticated recipient before SQL. Agents must never reconstruct grading or wants from redacted reads or refresh an unknown operation's preconditions or recipient.

Terminal rejection contracts (`storage_command_rejected`, `storage_creation_rejected`, `storage_import_rejected`) are included in generated endpoint Markdown and full LLM exports; accepted 200 schemas stay accepted-only. MCP `tools/list` advertises `outputSchema` and status-keyed errors in `_meta["holofolder.com/errorSchemas"]`; terminal tool errors have `isError:true` and matching text and structured JSON. An ordinary 409 is not proof that a request never committed.

Identity: use the native inventory and storage operations for copies, slots and wants. Public legacy species-row CRUD, `get_legacy_pokemon_analytics` and `resolve_import` are removed with no aliases. `get_pokemon_set_slots` is dex-grouped species data at `/pokemon/sets/{id}/slots`. Activity filters physical copies by `inventoryItemId`; durable command `itemId` fields are not renamed. Catalog cards, sets and series declare `game:"pokemon"`; application IDs, canonical IDs and reviewed aliases are globally unique and opaque. Source-keyed `externalIds` are provider-local evidence. No other game is supported.
