---
title: Set checklist drafts
summary: Internal previews of copied set and verified finish scopes, pending runtime enablement.
---

Set checklist creation is currently an internal preview, not enabled saved creation.

The preview uses a full mirrored card list, including Trainers, supporters, items, Energy, repeated Pokémon, secrets and subsets. Choose a language and review the exact included card targets. Base checklist accepts any finish. A variant checklist includes only explicitly selected, catalog-verified Normal, Holo, Reverse holo or Jumbo finishes. Unsupported or missing evidence remains unavailable, regardless of rarity, price or grade. This is a scoped checklist, not a guarantee of universal master-set completeness.

Optional promos must be selected explicitly from an actual catalog set, and exclusions are shown before the draft is prepared. The copied scope does not subscribe to catalog updates. Current-target completion follows later edits; cards in free slots are extras. Removing a target removes that requirement.

Retained scope evidence can be viewed offline. Loading uncached catalog evidence and preparing creation require a connection. Preparing the internal draft does not save a binder, acquire cards, record wanted entries or submit an offline operation. Durable creation and scope persistence remain gated.

Existing catalog APIs support `list_sets`, `get_set`, `list_cards` and `get_card` with `catalog:read`. Page the card listing to browse a full set. There is no public set-preset creation operation in this release.
