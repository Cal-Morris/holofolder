## Before you send a request

- **Real requests, real changes.** Write operations change your account. Start with a read-only key and a GET request.
- **Permissions apply.** The explorer uses the same subscription, permissions and rate limits as your own integrations.
- **Retry safely.** Operations that create binders or comparison jobs require an `Idempotency-Key`. Collection changes use the fingerprint from your last read.

See [API conventions](/docs/contracts) for pagination, errors and limits. Prefer an AI assistant? [Connect through MCP](/docs/mcp) instead.
