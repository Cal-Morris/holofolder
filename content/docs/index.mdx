Holo Folder's developer interfaces bring the card catalog, binders, wanted lists and prices to your scripts and AI tools.



## Two ways to connect

| Interface | Authentication | For |
| --- | --- | --- |
| REST API | Personal API key | Scripts and integrations |
| MCP | OAuth consent | AI clients |

MCP clients sign in and request permission. They do not need an API key.

## Access

A current Premium subscription or lifetime licence is required. Signup trials do not include developer access. Partners follow the paid collection owner's access and current membership.

Start with [API keys](/docs/api-keys) or [MCP connections](/docs/mcp).

## Card data and images

The API exposes the data actually available in Holo Folder's mirror. Unknown values stay unknown. Images come only from our Cloudflare R2 mirror; a missing mirrored image is reported as unavailable.

Card data is sourced from TCGdex and the providers identified in each result. Pokémon card images are © The Pokémon Company, Nintendo, Creatures and GAME FREAK. Data licensing does not grant rights to the card artwork.
